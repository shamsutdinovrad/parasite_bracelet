# Браслет, анализирующий речь на наличие слов-паразитов

### Цель и практическая направленность:
Целью проекта было создание прототипа носимого на руке устройства для улучшения качества речи носителя. Практическая задача - детекция слов-паразитов в речи конкретного человека в реальном времени и отклик в виде вибрации и индикации слова на дисплее. 

### Для решения задачи я обрабатывал аудиоданные в два этапа:

1. **Биометрия голоса**: Чтобы устройство не реагировало на чужую речь, мной на `MFCC и спектральных характеристиках` звука был обучен `RandomForestClassifier`. Датасет размером примерно в 100 аудио (50 с моим голосом, 50 с чужими) длительностью примерно по 30 секунд собирал сам, записывая аудио в различных помещениях для повышения устойчивости модели к шуму.
Код для обучения модели: [bracelet_model.py](bracelet_model.py).

2. **Speech-to-Text преобразование**: Распознавание текста реализовал с помощью модели `Vosk` (vosk-model-small-ru-0.22), эта модель позволила добиться высокой скорости обработки, что было важно для обработки в реальном времени. Далее скрипт анализировал текст на наличие заданного списка слов-паразитов. Код сервера и обработки: [bracelet_main.py](bracelet_main.py).

### Hardware:
Контроллер: `ESP 32-S3-Zero`

Микрофон: `INMP441`

Аккумулятор: `3.7 В, 320 мАч`

Контроллер питания: `TP4056`

Дисплей: `OLED`

Подлючение осуществлялось по `WebSocket`

Код для работы микроконтроллера: [esp32.ino](esp32.ino)

## Результат:
Был создан работающий прототип устройства, который успешно идентифицирует мой голос и сигнализирует о найденных словах-паразитах. В ходе тестирования уверенность идентификации моего голоса составила около 0.8 на тестовых записях, однако при обработке звука в реальном времени уже с микрофона браслета уверенность модели снижалась, особенно при шепоте и сильной окружающей зашумленности. Этот результат показал мне, что для обучения модели стоило использовать еще более зашумленные данные.
